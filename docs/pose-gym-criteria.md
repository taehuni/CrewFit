# 헬스장 운동 지침 카탈로그

검토일: 2026-11-18. 데이터 원본: `shared/gymCriteria.js`. 클라이언트 파일은 동일 자료를 다시 내보낸다.

## 목적과 지원 범위

머신·프리웨이트·케이블·맨몸 운동의 참고 지침을 찾고, 향후 영상 평가 항목을 설계하기 위한 자료다. 이 자료를 추가했다고 해당 운동의 자동 분류·실시간 평가가 구현되는 것은 아니다. 현재 실시간 피드백은 지원하는 맨몸 스쿼트·제자리 런지·바닥 푸시업 구성으로 한정한다.

`reference-only`는 공식 원문의 운동 방법을 확인한 참고 지침이다. `pending`은 정확히 일치하는 운동 변형의 근거를 아직 확인하지 못했으므로 평가 지침을 제공하지 않는다. 지원 여부를 운동 이름만으로 유추하지 않는다.

## 자료 구성과 근거 구분

- `sources`: 직접 확인한 ACE 또는 NASM의 해당 운동 원문. 기관의 일반 홈페이지나 검색 결과를 근거로 쓰지 않는다.
- `criteria`: 해당 변형에 대한 운동 방법을 짧게 한국어로 요약한다. 원문을 통째로 복제하지 않는다.
- `observable`, `preferredView`: 원문의 주장을 그대로 옮긴 것이 아닌, 화면에서 검토할 수 있을 것으로 보는 **개발 측 설계 후보**다. 검출기 정확도나 단안 영상 평가의 타당성이 검증됐다는 의미가 아니다.
- `notObservable`: 통증, 중량 적합성, 복압, 근육 활성, 지지 압력, 관절 내부 상태 등 영상만으로 판단할 수 없는 항목과 종목별 가림 한계다.

평가 임계 각도·합격 점수·부상 위험 점수를 임의로 만들지 않았다. 원문이 자세 예시로 각도를 제시하더라도 이를 모든 사용자에게 적용되는 카메라 합격 기준으로 전환하지 않는다. 체형, 가동성, 촬영 방향, 변형 동작에 따라 달라진다.

## 변형을 섞지 않는 원칙

1. 크런치 원문의 허리 바닥 유지 조건을 전체 싯업에 적용하지 않는다. 싯업은 별도 근거 확인 전까지 `pending`이다.
2. 버피는 푸시업 포함형과 스텝백·푸시업 생략형을 구분한다. 변형을 수행했다는 이유로 잘못된 자세로 채점하지 않는다.
3. 친업의 언더그립 지침을 모든 풀업에, 가슴 지지 로우를 벤트오버 로우에, 특정 케이블 프레스를 모든 머신 프레스에 확대 적용하지 않는다.
4. ACE의 어깨 연구 글에서 숄더프레스, 인클라인 프론 로우, 시티드 리어 레터럴 레이즈는 각각 명시된 시범 절차를 인용했다. 근전도 연구 결과는 카메라 평가의 유효성 근거가 아니다.
5. 딥과 킥백은 ACE 자체 연구 PDF의 해당 운동 설명을 사용한다. NASM 벤치 딥 페이지는 근육 표에 다른 운동 내용이 섞인 오류가 있어 이 카탈로그의 근거로 사용하지 않았다.

## 실시간 평가로 확대하기 전 필요한 검증

운동과 기구·변형을 먼저 구분하고, 필요한 관절이 보이는 촬영 방향을 정의해야 한다. 대표 영상에서 반복 단계와 관찰 항목을 전문가가 표시한 뒤 정확도·오탐·판정 보류를 검증한다. 가림·전환·여러 사람·모호한 방향에서는 평가하지 않는다. 단일 영상으로 알 수 없는 내용을 확정적인 피드백으로 출력하지 않는다.

분류 API가 운동 이름을 반환하는 것, 운동 지침이 존재하는 것, 검증된 실시간 평가기가 있는 것은 별개 단계다. 카탈로그에서 참고 지침과 현재 측정 지원 범위를 분리해 표시한다.

## 확장 기록 저장 계약

`20261118_pose_sessions_extended.sql`은 검토용이며 자동 실행하지 않는다. 기존 3종의 방향·횟수·관찰 키는 유지한다. 카탈로그 근거 확인 종목은 `view: auto`, `reps: null`로 저장한다. 관찰 키 `criterion_N`은 해당 운동의 `observable` 배열 인덱스이며, `source_id`는 동일 운동의 카탈로그 ID여야 한다. 이 배열은 영상 관찰 후보이므로 기록이 검증된 점수나 전문가 판정이라는 뜻은 아니다.

기타 직접 입력 운동은 `manual_other`, `view: manual`, 이름 1~60자, 횟수 없음, 평가 항목 없음으로 저장한다. 보류 중인 싯업에 다른 운동의 기준을 적용하지 않는다. 영상·원시 관절·임의 출처 URL은 요약 기록에 넣지 않는다. 마이그레이션 실행 전에는 기존 기록 조회와 기존 3종 저장을 구 필드로 재시도한다. 확장 기록 저장은 설정 필요 오류로 현재 결과를 유지하며, 다른 종목으로 바꿔 저장하지 않는다.

## 출처 색인

각 운동의 상세 출처 URL은 데이터의 `sources`와 앱의 해당 운동 상세 화면에서 확인할 수 있다. 출처 내용과 장비·변형이 일치하는지 새 항목마다 검토하고, 변경 시 검토일을 갱신한다.
